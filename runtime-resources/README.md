# Bundled runtime resources

Runtime files include text game catalogs, the in-game overlay, keyboard helpers, archive extraction, and the Pak loader. Game installation paths are configured by each user at runtime.

Electron is downloaded from its official release with checksum verification. The MEGA worker is compiled from the pinned Git submodule. Game artwork is loaded from external URLs and is not redistributed here. Obsolete setup packages, built-in repair rules and standalone fixer executables are not distributed.
